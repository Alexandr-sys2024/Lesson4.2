# Lesson4.2

## 📌 Описание проекта
Lesson4.2 — это система управления пользователями с разными уровнями доступа. 
Проект демонстрирует основы ООП в Python, включая инкапсуляцию, наследование и работу с пользователями.

## 🚀 Функционал
- 📌 **Класс `User`** — обычный пользователь с уникальным ID и именем.
- 🔑 **Класс `Admin`** — расширенный пользователь с правами администратора.
- ➕ **Добавление пользователей в систему**
- ❌ **Удаление пользователей из системы**
- ✏️ **Изменение имени пользователя**
- 🔍 **Вывод списка пользователей**
